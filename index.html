Free 2-Minute Google Sheet Backend Guide

  1. Create a new Google Sheet at sheets.new
  2. Click Extensions > Apps Script
  3. Copy the code from google_apps_script.js file and paste it into Code.gs.
  4. Click Deploy > New deployment, select type Web App.
  5. Set "Execute as: Me" and "Who has access: Anyone".
  6. Click Deploy, copy the Web App URL, and paste it into your settings!
